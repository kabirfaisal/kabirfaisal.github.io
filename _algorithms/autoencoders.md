title: "Autoencoders &amp; denoising autoencoders"
---
<p>An autoencoder compresses an input to a small code and reconstructs it, learning the data&rsquo;s structure in the bottleneck. A <em>denoising</em> autoencoder is trained to rebuild a clean input from a corrupted one, which makes its features more robust and turns it into a natural imputer: mark missing values as corruption and read off the reconstruction.</p>
